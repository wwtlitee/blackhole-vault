# 黑洞保险箱

**版本 2.1.0b** · 单文件、离线使用的本地凭据管理工具。

把账号、API 信息、链上地址和平台 UID 放在同一个可搜索的保险箱里。应用提供黑洞与黑客两种主题，数据在当前浏览器中加密保存，无需注册账号。

## 使用

1. 下载本仓库的 `index.html`，保存到自己的电脑。
2. 用支持 Web Crypto API 和本地存储的现代浏览器打开它。
3. 首次使用时设置主密码，之后用主密码解锁。
4. 在「备份 / 设置」中导出加密备份，并妥善保存到独立位置。

应用的脚本、样式、图标和绘制代码都包含在 HTML 内，无需安装依赖或连接服务器。若浏览器限制本地文件的加密或存储功能，请换用支持该功能的浏览器环境。

## 功能

- 四类条目：账号 / 密码、平台 / API、链 / 地址、平台 / UID。
- 单条与批量录入、搜索、重复检查、手动排序和分类变更。
- AES-256-GCM 加密，使用 PBKDF2 从主密码派生密钥。
- 加密 JSON 备份导出与导入、写入前快照、写入失败恢复。
- 空闲自动锁定、敏感字段延时收起、未保存编辑确认。
- 黑洞与黑客双主题、移动端布局、键盘操作、减弱动态效果支持。

## 数据与备份

数据保存在当前浏览器环境的本地存储中，不会自动同步到其他浏览器、设备或网站。更换浏览器配置、清理站点数据或移动使用环境前，请先导出备份并确认能解锁。

主密码无法找回。不要把主密码和加密备份放在同一位置。剪贴板清理依赖浏览器权限，无法清除系统剪贴板历史或其他软件的同步副本。

此工具没有云端恢复服务，也未提供独立安全审计结论。

开发者可安装 Node.js 后运行：

```sh

```

脚本检查发布文件白名单、应用哈希与版本、内联脚本语法与 CSP 哈希、离线依赖以及常见凭证特征。它不会打开保险箱或读取浏览器数据；静态检查不能代替真实数据恢复验证或完整安全审计。

文件说明：

- `index.html`：完整应用。
- `CHANGELOG.md`：产品变更与本次源码公开说明。
